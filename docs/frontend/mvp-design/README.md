# مین‌حساب – پنل نمایشی (HTML/CSS/JS)

بدون بیلد و بدون سرور: `index.html` را باز کنید (یا `npx serve .`).

## ساختار
```
index.html            → هدایت به داشبورد
dashboard.html …      → هر صفحه یک فایل کوچک است (فقط data-page روی body)
auth.html, landing.html → طراحی‌های قبلی شما (بدون تغییر)
assets/css/shell.css       → توکن‌ها، سایدبار، تاپ‌بار (استخراج‌شده از panel.html)
assets/css/components.css  → کارت، جدول، فرم، نمودار، دیالوگ
assets/js/shell.js         → تم، جمع‌شدن منو، دراور موبایل، زیرمنو
assets/js/app.js           → منو، داده‌ی نمایشی و رندر صفحات
assets/js/fiscal.js        → وضعیت مشترک سال/دوره مالی (localStorage)، اعتبارسنجی، بنر و چیپ
assets/js/fiscal-pages.js  → راه‌اندازی مالی، سال‌های مالی، دوره‌های مالی
```

## صفحات
داشبورد · گزارش‌ها · دفتر روزنامه · ثبت سند مرکب (کنترل توازن زنده) · تراز آزمایشی ·
بانک و صندوق · چک‌ها (اعتبارسنجی شناسه صیادی) · POS (جلوگیری از ترمینال تکراری) ·
فاکتورهای فروش · فاکتور جدید (تخفیف، مالیات، چند روش پرداخت، مانده) · خرید ·
مشتریان و تأمین‌کنندگان · شعب · کاربران و نقش‌ها · تاریخچه تغییرات · تنظیمات

## افزودن صفحه
۱. یک ورودی در `PAGES` (app.js) و یک مورد در `NAV` اضافه کنید.
۲. فایل `<slug>.html` را از روی یکی از صفحات کپی کنید و `data-page` را عوض کنید.
صفحه‌ی جدولی فقط ستون‌ها (`cols`)، فیلتر، آمار و فرم افزودن را می‌خواهد.

## هماهنگی با پروژه‌ی Next.js
- توکن‌های رنگ همان `globals.css` شما هستند (`--primary`, `--accent`, `--border` …).
- جدول‌ها قرارداد URL مستندات DataTable را دارند: `?page=&limit=&search=` (تغییر جستجو، صفحه را به ۱ برمی‌گرداند).
- همه داده‌ها نمایشی‌اند؛ مبالغ ریال، تاریخ شمسی با `Intl`. منطق حسابداری واقعی باید در بک‌اند بماند.

## سال و دوره مالی (SET-001 / ACC-006)
- `fiscal-setup.html` ویزارد ۴ مرحله‌ای: تعریف سال ← ایجاد دوره‌ها (ماهانه/فصلی) ← باز کردن دوره‌ها (حداقل یکی) ← اتمام.
- `fiscal-years.html` لیست و افزودن سال (با کنترل هم‌پوشانی و تولید خودکار دوره‌ها).
- `fiscal-periods.html` ایجاد دوره، شروع بازبینی، بستن (تأیید صریح)، بازگشایی (دلیل اجباری + مجوز) و تاریخچه‌ی قفل.
- وضعیت‌ها: باز · در بازبینی · در حال بستن · بسته · بازگشایی‌شده. فرض UI: ثبت سند فقط در «باز» و «بازگشایی‌شده» مجاز است.
- Shell: چیپ وضعیت کنار تاپ‌بار، زیرنویس برند، و بنر ثابت برای «بدون دوره»، «بدون دوره‌ی باز» و «دوره‌ی جاری بسته».
- «حالت نمایشی» (بالای صفحات سه‌گانه) برای دیدن همه‌ی stateها: عادی، دوره‌ی جاری بسته، بدون دوره‌ی باز، بدون سال مالی.

## تغییرات جدول‌ها (نسخه‌ی ۳)
- همه‌ی جدول‌ها ستون «ردیف» دارند. چک‌ها: ردیف ← شماره چک ← شناسه صیادی ← نوع، طرف حساب، بانک، مبلغ، **تاریخ ثبت**، سررسید، وضعیت.
- ثبت چک: اگر سررسید قبل از تاریخ ثبت باشد، فرم خطا می‌دهد و دکمه‌ی ذخیره غیرفعال می‌ماند. شماره چک (برای همان بانک) و شناسه صیادی تکراری هم رد می‌شود.
- فاکتور فروش و خرید: ستون «تخفیف» (مبلغ و درصد، یا «بدون تخفیف»)، فیلتر تخفیف، ستون «شرح».
- فاکتور فروش: ستون «فروشنده» و «پورسانت»، فیلتر فروشنده، کارت عملکرد هر فروشنده؛ در فاکتور جدید: انتخاب فروشنده، پورسانت محاسبه‌شده و فیلد شرح.
- نرخ پورسانت نمایشی در `RATE` (app.js) است: ۲٪، ۳٪ و ۲٫۵٪.
