# TECH-012 — Observability Stack

- وضعیت: پذیرفته‌شده

## تصمیم

Observability بر اساس این چهار قابلیت ساخته می‌شود:

- Structured Logging
- Metrics
- Tracing
- Health / Readiness Checks

Error Tracking و Alerting نیز باید روی همین لایه سوار شوند.

ابزار مشخص ممکن است بر اساس محیط نصب انتخاب شود، ولی Application Contract به Vendor خاص وابسته نخواهد شد.
