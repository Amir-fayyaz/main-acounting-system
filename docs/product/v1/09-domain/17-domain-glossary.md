# واژه‌نامه دامنه

| واژه | تعریف |
|---|---|
| Business Transaction | رخداد کسب‌وکاری مانند خرید، فروش یا پرداخت |
| Accounting Effect | اثر مالی استخراج‌شده از یک رخداد کسب‌وکاری |
| Accounting Document | سند قطعی ثبت‌شده در حسابداری |
| Party | هویت مشترک شخص/سازمان در نقش‌های مختلف |
| Financial Dimension | محور تحلیلی برای طبقه‌بندی گزارش‌پذیر اثر مالی |
| Fiscal Year | دوره سالانه مالی شرکت |
| Fiscal Period | زیر دوره عملیاتی سال مالی که وضعیت باز/بسته دارد |
| Action Plan | مجموعه اقداماتی که Agent برای دستیابی به نتیجه پیشنهاد می‌کند |
| Domain Event | رخدادی که تغییری مهم و قابل توجه در دامنه را اعلام می‌کند |
| Reversal | عملیات معکوس مرتبط با یک عملیات ثبت‌شده قبلی |
| Correction | عملیات اصلاحی که خطای ثبت‌شده را با عملیات جدید جبران می‌کند |
| Provider | سامانه یا سرویس بیرونی که از طریق Adapter به محصول متصل می‌شود |
| Exception | وضعیت یا رخدادی که نیازمند بررسی یا اقدام است |
| Projection | نمایش خواندنی داده برای گزارش، بدون مالکیت حقیقت دامنه |
